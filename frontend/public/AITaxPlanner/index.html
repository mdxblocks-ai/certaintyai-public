Architecture workstream

Open ingestion → Medallion → RAG grounding → decoupled planner

The data backbone. The most important boundary is the dashed one: the planner consumes calculation outputs through a contract, never coupled to the compliance engine's roadmap.

Medallion data foundation (NoSQL lake)

🟤 Bronze · Raw
1040 / 1120-S / K-1 / ledgers, as landed. 300+ connectors, open APIs.
→
⚪ Silver · Conformed
Normalized, deduped, PII-handled, mapped to canonical planning model.
→
🟡 Gold · Analytics
Entity-aware features: QBI base, comp ratio, carryforwards, jurisdiction.
→
🔵 RAG · Vector store
Chunks + embeddings + tags from tax law, workpapers, prior returns → grounded, cited context.

🟢 Planning service (this product)

Forecasting + scenario simulation + constrained optimization + agentic orchestration + explanation layer. Owns the roadmap.

⛓ Integration contract — the decoupling boundary

Planner calls calc-svc@1.4 with inputs, receives liability + line items. No shared schema, no shared release train. Swap or upgrade the engine without touching the planner.

scenario simulation

constrained optimization

agentic workflow

governance
